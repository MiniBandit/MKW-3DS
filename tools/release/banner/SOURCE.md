# Banner tool provenance

These tools were synchronized from the development workspace on 2026-10-30.
The publication adapters use explicit external paths, support the current
DSKM version, preserve the 45-degree release view, and package the separately
supplied audio. The ground shadow is procedural so no MK7 banner model or
texture is required. Offline Blender preview and cached-production repair
scripts remain development tools. See docs/HOME-BANNER.md for usage and the
remaining fresh-disc and HOME Menu validation limits.
