# Build the animated HOME banner

The banner shows Funky Kong on the Flame Runner in his bike cannon pose (the
original 30-frame `jump` loop), under the Mario Kart Wii logo, with the start
of the Wii Disc Channel banner sound. The bike is assembled from the original
part placement data, as in races, with the wheels hanging at full travel. The
soft ground shadow is generated by code.

The repository supplies the icon and logo PNGs and the earlier banner audio. It does not supply the main
model, animations, CGFX, or compiled banner. Generate those from your own USA
RMCE01 disc into an external work directory. `tools/build.py` runs every step
below (its `banner` stage) and uses the result in the CIA; these banner tools
on their own do not compile the game or package a CIA.

## 1. Prepare dependencies

Install the dependencies described in [MANUAL-BUILD.md](MANUAL-BUILD.md),
including the pinned noclip and gclib sources, the noclip patch, Node packages,
Python packages and a host C++17 compiler. Install bannertool separately.
Acquire pycgfx separately at the revision listed in `dependencies.json`:

```sh
git clone https://github.com/skyfloogle/pycgfx.git /external/pycgfx
git -C /external/pycgfx checkout 1f78850086f3a77c41e07162e842f97a5bf3c18a
python3 -m pip install gltflib==1.0.13
```

Use the same Python environment for all stages. It must also contain NumPy,
Pillow and gclib. The pycgfx checkout is not bundled; no explicit license file
was found in the locally inspected pinned checkout.

## 2. Extract the original inputs

```sh
python3 tools/release/extract_banner_sources.py --disc /external/RMCE01.iso --output /external/home-banner
```

This extracts selected archives, unpacks them and records their hashes. The
models and animations come from `Race/Kart/la_bike-fk.szs`, the bike's wheel,
handle and seat placement from `Race/Common.szs`, lighting from
`Scene/UI/MenuSingle.szs`, and the banner sound from `opening.bnr`. The tool
rejects output inside this repository.

## 3. Export geometry and animation

```sh
python3 tools/release/build_banner_model.py export --work /external/home-banner
```

This bundles the two required offline exporters, exports the original BRRES
geometry and animation bank, and records the selected input hashes. It uses
only the extracted files; it does not read a prebuilt banner model.

## 4. Prepare the banner scene and baked materials

```sh
python3 tools/release/build_banner_model.py scene --work /external/home-banner
```

This compiles the small host light-texture helper, evaluates the original
MenuSingle lighting, decodes source textures and writes the animated scene
under `/external/home-banner/production/`. Use `--cxx /path/to/compiler` to
select another C++17 compiler. Generated lighting headers remain outside the
repository and do not replace the game's generated headers.

## 5. Convert the scene to CGFX

```sh
python3 tools/release/build_banner_model.py cgfx --work /external/home-banner --pycgfx-root /external/pycgfx
```

The converter checks the dependency revision and rejects a CGFX at or above
512 KiB. `production/CGFX_BUILD.json` records geometry, bones, animation
periods and material layout. The result is `production/banner.cgfx`.

## 6. Prepare the icon

Resize the supplied 64-pixel source into the two SMDH sizes:

```sh
python3 -c "from PIL import Image; from pathlib import Path; p=Path('/external/home-banner/production'); im=Image.open('tools/release/artwork/icon.png').convert('RGBA'); [(im.resize((n,n),Image.Resampling.LANCZOS).save(p/f'icon{n}.png')) for n in (48,24)]"
bannertool makesmdh -s "Mario Kart WiiDS" -l "Mario Kart WiiDS" -p "Epic0522/ethanseagull" -i /external/home-banner/production/icon48.png -si /external/home-banner/production/icon24.png -o /external/home-banner/production/icon.icn
```

## 7. Package the banner with its sound

`tools/build.py` uses the Disc Channel banner sound from your disc
(`opening.bnr`, `meta/sound.bin`: 10.94 s of 32 kHz stereo DSP-ADPCM). It
decodes it with `tools/wii_banner_sound.py`, resamples it to 44.1 kHz and cuts
it at the 3.000 s banner limit with a 0.2 s fade, makes a PCM16 CWAV with
`bannertool makecwav`, builds the banner with `bannertool makebanner`, and
puts that CWAV in place of the sound makebanner wrote:

```sh
python3 tools/wii_banner_sound.py /external/home-banner/archives/opening.bnr disc.wav
ffmpeg -i disc.wav -af "aresample=44100:resampler=soxr,atrim=end_sample=132300,afade=t=out:st=2.8:d=0.2" -c:a pcm_s16le -ar 44100 banner.wav
bannertool makecwav -i banner.wav -o banner.bcwav
bannertool makebanner -ci /external/home-banner/production/banner.cgfx -a banner.wav -o graphics.bnr
```

`Builder.banner_sound` in `tools/build.py` does the last step. The CBMD header
gives the CWAV's offset at 0x84.

`tools/release/artwork/banneraudio.wav` is the earlier banner sound (stereo
PCM16, 44,100 Hz, about 3.003 s). To use it instead:

```sh
bannertool makebanner -ci /external/home-banner/production/banner.cgfx -a tools/release/artwork/banneraudio.wav -o /external/home-banner/production/banner.bnr
```

For maintenance, `extract_banner_audio.py INPUT OUTPUT` can recover CWAV
from a decrypted CIA or an extracted CBMD banner. It checks the CIA's ExeFS
banner hash, writes provenance beside the audio, and refuses to overwrite an
existing output. Normal builds need no donor CIA.

The makerom command that uses the banner and `icon.icn` is in
[MANUAL-BUILD.md](MANUAL-BUILD.md#8-home-banner-and-cia).

## Verification status

The CGFX is about 422 KB (the limit is 512 KiB), with 2,214 vertices. Funky's
mesh keeps per-vertex rigid skinning (one bone per vertex) without back faces;
the bike parts are rigid nodes with back faces. On 2026-11-13 the banner
showed, animated and played its sound on a New 3DS HOME Menu without freezing.
HOME plays banner animation at 60 ticks a second: the cannon loop runs over
48 ticks (0.8 s). The scale and height keep the whole bike on screen at every
angle of HOME's turn; Funky's head may cover the bottom of the logo.
