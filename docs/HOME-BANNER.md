# Build the animated HOME banner

The banner uses Mario, Standard Kart M and the original 49-frame `good`
one-handed cheer with its smiling face texture. The fixed scene recipe
retains the rear-wheel scale, steering arm, softened head motion, repaired
rear axle, 45-degree view and logo sampler correction from the release banner.
The soft ground shadow is now generated by code; no MK7 banner asset is needed.

The repository supplies the icon and logo PNGs and the approved banner audio. It does not supply the main
model, animations, CGFX, or compiled banner. Generate those from your own USA
RMCE01 disc into an external work directory. These banner-only tools do not
compile the game, convert the full resource set, or package a CIA.

## 1. Prepare dependencies

Install the dependencies described in [MANUAL-BUILD.md](MANUAL-BUILD.md),
including the pinned noclip and gclib sources, the noclip patch, Node packages,
Python packages and a host C++17 compiler. Install bannertool separately.
Acquire pycgfx separately at the revision listed in `dependencies.json`:

```sh
git clone https://github.com/skyfloogle/pycgfx.git /external/pycgfx
git -C /external/pycgfx checkout 1f78850086f3a77c41e07162e842f97a5bf3c18a
python3 -m pip install gltflib==1.0.13
```

Use the same Python environment for all stages. It must also contain NumPy,
Pillow and gclib. The pycgfx checkout is not bundled; no explicit license file
was found in the locally inspected pinned checkout.

## 2. Extract the original inputs

```sh
python3 tools/release/extract_banner_sources.py --disc /external/RMCE01.iso --output /external/home-banner
```

This extracts selected archives, unpacks them and records their hashes. The
model comes from `Race/Kart/mdf_kart-mr.szs`, assembly parameters from
`Race/Common.szs`, and lighting from `Scene/UI/MenuSingle.szs`. Menu driver
and kart archives are also retained for reference. The tool rejects output
inside this repository.

## 3. Export geometry and animation

```sh
python3 tools/release/build_banner_model.py export --work /external/home-banner
```

This bundles the two required offline exporters, exports the original BRRES
geometry and animation bank, and records the selected input hashes. It uses
only the extracted files; it does not read a prebuilt banner model.

## 4. Prepare the banner scene and baked materials

```sh
python3 tools/release/build_banner_model.py scene --work /external/home-banner
```

This compiles the small host light-texture helper, evaluates the original
MenuSingle lighting, decodes source textures and writes the animated scene
under `/external/home-banner/production/`. Use `--cxx /path/to/compiler` to
select another C++17 compiler. Generated lighting headers remain outside the
repository and do not replace the game's generated headers.

## 5. Convert the scene to CGFX

```sh
python3 tools/release/build_banner_model.py cgfx --work /external/home-banner --pycgfx-root /external/pycgfx
```

The converter checks the dependency revision and rejects a CGFX at or above
512 KiB. `production/CGFX_BUILD.json` records geometry, bones, animation
periods and material layout. The result is `production/banner.cgfx`.

## 6. Prepare the icon

Resize the supplied 64-pixel source into the two SMDH sizes:

```sh
python3 -c "from PIL import Image; from pathlib import Path; p=Path('/external/home-banner/production'); im=Image.open('tools/release/artwork/icon.png').convert('RGBA'); [(im.resize((n,n),Image.Resampling.LANCZOS).save(p/f'icon{n}.png')) for n in (48,24)]"
bannertool makesmdh -s "Mario Kart Wii 3DS" -l "Mario Kart Wii 3DS Redux" -p "Redux" -i /external/home-banner/production/icon48.png -si /external/home-banner/production/icon24.png -o /external/home-banner/production/icon.icn
```

## 7. Package the banner with the included audio

`tools/release/artwork/banneraudio.wav` is the current sound supplied by the
maintainer. It replaces the older upstream CIA sound. The source is stereo
PCM16 at 44,100 Hz, with 132,414 samples per channel (about 3.003 seconds).
It is copied unchanged, preserving its existing fades. Its SHA-256 and format
are recorded in the artwork manifest. Do not substitute audio from an older CIA.

```sh
bannertool makebanner -ci /external/home-banner/production/banner.cgfx -a tools/release/artwork/banneraudio.wav -o /external/home-banner/production/banner.bnr
```

For maintenance, `extract_banner_audio.py INPUT OUTPUT` can recover CWAV
from a decrypted CIA or an extracted CBMD banner. It checks the CIA's ExeFS
banner hash, writes provenance beside the audio, and refuses to overwrite an
existing output. Normal builds use the included sound and need no donor CIA.

Use `banner.bnr` and `icon.icn` in the separately documented manual makerom
command. No CIA is built by these banner tools.

## Verification status

The export, scene and CGFX stages passed locally using previously extracted
original Mario/Standard Kart and MenuSingle files. The output was 426,600
bytes with 26 bones and 21 animated tracks. The original frame-20 geometry
comparison passed with maximum error below 0.0001 source units.
Packaging with bannertool also passed; audio extracted from the new banner
matched the supplied WAV sample rate, channel count and PCM samples exactly.

A fresh disc-extraction run and a HOME Menu
visual/audio check of this reconstructed source pipeline remain outstanding.
These host conversion results do not establish byte identity with the old
banner or physical-console acceptance of the new procedural ground shadow.
